# HomePorte — сайт-визитка

Одностраничный статический сайт: `index.html` + `css/style.css` + `js/main.js`.
Без сборщиков — папку можно загрузить на любой хостинг как есть
(или открыть `index.html` двойным кликом для проверки).

## Как заменить или добавить фото

Все фото лежат в `assets/img/`:

| Папка / файл | Что показывает | Рекомендуемый размер |
|---|---|---|
| `hero/hero-1.jpg` | 1-й слайд на главном экране | 1920×1080 (горизонтальное) |
| `hero/hero-2.jpg` | 2-й слайд | 1920×1080 |
| `hero/hero-3.jpg` | 3-й слайд | 1920×1080 |
| `about/about-1.jpg` | Фото в блоке «О нас» | 1200×800 (горизонтальное) |
| `gallery/01.jpg … 08.jpg` | Плитка «Наши работы» | 900×1200 (вертикальное) |

Чтобы заменить фото — просто положите новый файл с тем же именем.
Если хочется поменять подписи под работами, откройте `index.html`
и найдите текст в блоке `<!-- ГАЛЕРЕЯ -->` — подписи в строках
`<p class="gcard__caption">…</p>` и `data-caption="…"`.

Оригиналы присланных фотографий сохранены в `assets/img/src/`.

## Контакты и реквизиты

Телефоны, адрес шоурума, соцсети и реквизиты ИП — всё в `index.html`,
ищется простым поиском по тексту.
