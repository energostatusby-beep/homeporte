# HomePorte

Статический сайт: `index.html`, `guide.html`, `css/style.css`, `js/main.js`, `assets/img/`.
Запуск для просмотра: `python3 -m http.server 8766 --bind 127.0.0.1`.

## Проекты

34 карточки, 113 фотографий. Группировка выполнена 13 сентября 2026 года по визуальным признакам интерьеров. Это редакционная группировка, не подтверждённый реестр заказов. Названия и описания не содержат вымышленных адресов, сроков или объёмов.

Карточки находятся в разделе `#projects` в `index.html`. `projects.json` хранит ту же группировку для дальнейшего редактирования; браузер не загружает этот файл. При изменениях обновляйте оба файла. Дополнительные ракурсы раскрываются в карточке; просмотрщик листает фотографии только выбранного проекта. Старый якорь `#gallery` ведёт в раздел проектов.

14 сентября проект «Кремовые двери с расстекловкой» полностью включён в «Стеклянные двери у музыкальной зоны»: три фотографии в общей галерее.

14 сентября четыре фотографии (`40.jpg`–`43.jpg`) из карточки «Серые двери и стеновые панели» вынесены в отдельный проект «Серо-оливковые двери с карнизом».

14 сентября две карточки объединены в проект «Белые двери и стеновые панели» с тремя фотографиями.

14 сентября добавлен проект «Классический интерьер с каминной и гардеробной»: 14 новых снимков, преобразованных в JPEG для сайта. Оригиналы пользователя не изменены.

## Конструктор

Раздел `#constructor` скрыт атрибутом `hidden`. Сохранён для последующей доработки. Высота вводится вручную до 3000 мм; минимальная производственная высота не согласована. Визуализация схематичная. Свой RAL записывается в заявку, но не перекрашивает эскиз без подтверждённого соответствия цвета. Названия моделей описывают геометрию; каталожные артикулы ещё не предоставлены.

## Заявки

Квиз и быстрая форма подключены к серверной очереди SQLite с доставкой в Telegram. Токен хранится только в `.env`. Запуск и перенос на VPS: [server/README.md](server/README.md). GitHub Pages не исполняет сервер: автоматическая отправка доступна при запуске проекта через `npm start` или Docker на сервере.
