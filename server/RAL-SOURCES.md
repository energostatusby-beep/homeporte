# Палитра RAL Classic

216 уникальных четырёхзначных кодов. Состав коллекции: https://www.ral-farben.de/en/ral-classic

Приблизительные экранные HEX: https://gist.github.com/lunohodov/1995178 (ral_classic.csv, revision cba796219888052065c4735df093ab2a664889b0, получено 14.09.2026). Это стороннее экранное представление, не официальная цифровая библиотека RAL. Цвета и специальные эффекты согласуются по физическому образцу.

Данные включены в HTML; сеть и внешние API для палитры не требуются. Коды и HEX хранятся в data-ral/data-hex; выбор изменяет SVG и текст заявки. RAL Design и RAL Effect — отдельные коллекции и сюда не включены.
